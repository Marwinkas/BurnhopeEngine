# Burnhope 2026 — один движок

Старый `path.md` не удалять: справочник идей. Этот файл — закон. На конфликте побеждает он.

Цель: GPU-resident кадр на годы. Этот файл — **весь движок** (свет, модели, физика, UI, то что после ядра). M0–M10 — **порядок сборки**, не «на этом останавливаемся». Идея без решения «как лучше 2026» сюда не попадает; когда фича дойдёт — только так, не вторым пайплайном.

**Продукт — то, чем Unity не стал.** Инди-удобство (пресеты, inspector, Look, WASM) + техника класса 2026. **Свет реалистичный** (bake и/или realtime RTX) на **стилизованных материалах и картах** — это основной микс, не «или мультики или кино». Можно и полный PBR, и toon под тем же `sampleGI`. Сначала неизвестны; кадр растёт без смены архитектуры.

**Наш Nanite — через LOD, не через реалтайм.** visbuffer + meshlets + GPU cull + **3 готовых LOD**. В кадре только выбрать LOD и отбраковать куски. **Реалтайм-автонарезка запрещена:** нет DAG-cut, нет simplify, нет «сжать миллион tri на лету». Нарезка meshlets — только cooker при импорте.

**Пишем сразу правильно.** M0–M10 — порядок сборки одного кадра, не «сначала deferred, потом модерн». visbuffer, heap/bindless, Slang, Flecs, bake=`sampleGI` — с первого рабочего треугольника. Устаревшее (G-Buffer как цель, VkPipeline как архитектура, Shader Graph, ImGui) **не появляется даже временно**.

**Caps — не откат к легаси.** Одна архитектура; если у GPU нет фичи — тот же кадр без неё: нет mesh shader → LOD целиком indirect; нет DGC → `DrawIndexedIndirectCount`; нет `rayQuery` → Baked/Mixed/SSR (инди-дефолт). Это не второй движок и не Unreal 4. Hybrid/ReSTIR — когда дойдём по вехам (M8), сразу со SVGF, не «шумный прототип на годы».

Идеи кадра и продукта в этом файле **закрыты**. Дальше — писать. Marketplace, VR, консоли — не метрика старта. Bake и RTX **оба шипаются**: реалистичный свет на любой Look.

## 3. Кадр GPU-driven (2026)

CPU не строит draw-list и не знает, что видно. Он пишет transforms/lights в ReBAR. GPU: cull → visbuffer → shading.

```
N     CPU: input, Flecs, Jolt → packed transforms, light list, dirty bits
N-1   compute:
        1. instance cull (frustum + size) → выбрать **один из 3 заранее нарезанных LOD**
        2. HZB phase 1 (depth прошлого кадра)
        3. [mesh shaders] meshlet cull **этого** LOD (cone + sphere + HZB) — куски уже в файле
           [иначе] skip, рисуем выбранный LOD целиком indirect
        4. compact draw / DGC
        5. skinning ТОЛЬКО visible verts
        6. [Mixed/RTX] VSM dirty pages
        7. [Hybrid/RTX] ReSTIR → dirty RC
        8. froxel/cluster build (Baked/Mixed local lights, volumetrics)
N-2   graphics/compute:
        visbuffer (mesh/task **или** indexed LOD)
        HZB phase 2 (новый depth) + resolve скрытых
        material bin → shading compute (sampleGI + shadows)
        reflect(kReflMode)
        transparents (OIT, §14)
        post → present_wait
```

Статика без `TransformChanged`: skip 5–7. Packed matrices — compute, не CPU.

## 4. Рендер: visbuffer + куллинг (не классический deferred)

### 4.0 Какой отложенный в 2026

| Подход | Суть | Вердикт |
|---|---|---|
| Forward+ / clustered forward | Свет по тайлам, шейдинг в FS | Нет как primary: дивергенция материалов, overdraw |
| **Tiled/deferred G-Buffer** | albedo/normal/rough в 3–5 RT | **Не делаем.** Толстый bandwidth, visbuffer его убивает |
| **Visibility buffer** | `R32` (или R32+depth): Instance \| Meshlet \| Tri | **Наш кадр.** Шейдинг в compute, материалы после |
| Clustered / **froxels** | 3D сетка ламп (16×16×Z log) | **Да**, для Baked/Mixed local + fog. Не вместо ReSTIR |
| Texture-space shading | свет в UV меша | трава/мех, когда дойдём; тот же `sampleGI` |

Почему visbuffer, не G-Buffer: нормаль/UV достаём из meshlet по ID (кэш L1), нет 200+ bit/pixel GBuffer, material binning = одна волна / один shader, compute derivatives (`VK_NV_compute_shader_derivatives` если caps, иначе quad в mesh FS только на vis pass).

Vis pass: early-Z, **не** писать `gl_FragDepth` (это выключит Early-Z). Masked = `demote`. Conservative raster — не для vis (это воксели).

Кодировка `R32`: 10b instance | 14b meshlet | 8b tri. Если когда-нибудь overflow — `R64` vis, тот же shading.

**Clustered свет где живёт:** пресеты Baked/Mixed и локальные лампы без ReSTIR. Hybrid/RTX прямой = ReSTIR DI, froxel — **volumetrics / local без RT**, не второй deferred.

Material binning: visbuffer → histogram MaterialID → indirect per-mat. Без этого bindless в compute снова расходится.

VRS (content, не нейро): плоская поверхность 2×2, край/деталь 1×1. Не в vis pass (ломает ID). Только shading/post.

### 4.1 Модели — Nanite через LOD (реалтайм не режет)

Тот же выигрыш, что у Nanite в кадре: visbuffer, meshlets, HZB, shade только видимое. **LOD вместо автонарезки в реалтайме.**

| В кадре (реалтайм) | Только cooker (не кадр) |
|---|---|
| выбрать один из 3 LOD | simplify → LOD0/1/2 |
| meshlet cull уже готовых кусков | `buildMeshlets` 64/126 |
| visbuffer + compute shading | упаковка verts / cone / sphere |
| **запрещено:** cut, DAG, simplify, SW-raster, «сжать миллион tri» | |

Авторский меш в игре не `vkCmdDraw` целиком: либо невидимые meshlets LOD, либо весь выбранный LOD если нет mesh shaders.

**Cooker (обязательный путь, не runtime Assimp):**

fastgltf / OpenFBX → triangulate → MikkTSpace → **meshoptimizer** → `.bhmesh`.

meshoptimizer, этот порядок:

1. `optimizeVertexCache` (Forsyth) на исходнике  
2. `optimizeOverdraw` / `optimizeVertexFetch`  
3. `simplify` → **ровно 3 LOD** (near / mid / far)  
4. для каждого LOD снова cache/overdraw/fetch  
5. **каждый LOD** → `buildMeshlets` (64/126) + cone/sphere — порезка **только здесь**, не в кадре  

Без 4–5 meshlet-cull на плохой топологии врёт.

---

**Единица рисунка = meshlet, не меш**

| | Закон |
|---|---|
| Лимит | **64 verts, 126 tris**, индексы **uint8** |
| Pad | verts до 64, indices до кратности 32/64 (волна) |
| Cull meta | sphere, AABB, **normal cone**, material bitmask (без Nanite-error DAG) |
| 1 meshlet | по возможности 1 материал (иначе binning страдает) |
| Сортировка | Morton по центру — locality VSM/vis |

Instance: 32-bit handle + packed transform. Не копия вершин на instance.

---

**Вершины — два потока (не один fat vertex)**

Vis/cull/HZB читает только позиции. Шейдинг — атрибуты по vis-ID.

| Stream | Содержимое | Формат |
|---|---|---|
| A позиция | xyz в **AABB мешлета** | uint8/unorm8×3 или uint16; world float32 только если AABB огромный (cooker решает) |
| B атрибут | N, T, UV0, UV2 (lightmap) | **Q-tangent** 10_10_10_2; UV half2; UV2 unorm16 |
| C extra | bone indices/weights, color, bent/AO | weights unorm8×4, bones uint8×4; bent octa + AO u8 |

Не хранить tangent+bitangent+normal (Q-tangent восстанавливает B). Не `float3` normal. Не дублировать вершины «под unique UV» без weld в cooker — fetch умрёт.

Кожа: dual-quat FP16 в `.bhbone`, skinning compute **после** выбора LOD и (если mesh shaders) meshlet cull. Без mesh shaders — после instance HZB, весь выбранный LOD.

---

**Реалтайм не режет.** Cooker: simplify → **3 LOD** → каждый LOD в meshlets 64/126. Кадр: `lodIndex = 0|1|2`, потом cull. GPU не simplify и не кроит треугольники.

Видны 3 куска стены — 3 meshlet, не весь LOD. LOD может смениться целиком (hysteresis), не «половина персонажа LOD0, ухо LOD2».

| GPU | Кадр |
|---|---|
| **Mesh shaders** | instance → LOD 0/1/2 → task/mesh только по **meshlets этого LOD** |
| **Нет** | instance → LOD 0/1/2 → `DrawIndexedIndirectCount` **всего** этого LOD |

Мета (sphere/cone) в `.bhmesh` у каждого куска. Без mesh shaders pass cull кусков не запускаем — не эмулируем task shader и не делаем SW-raster «как UE».

**3 LOD (закон, не 6, не непрерывный DAG):**

| | Когда | Геометрия |
|---|---|---|
| LOD0 | близко | полный simplify-target, нарезан на meshlets |
| LOD1 | середина | ~¼–⅓ tri LOD0, снова нарезан |
| LOD2 | далеко | грубый, нарезан (кусков мало) |

Выбор: дистанция или projected size + hysteresis. Один LOD на instance на кадр. Не морф.

Дальше LOD2 — impostor / HLOD (§14). Не Gaussian как default.

Screen-size: instance < 1 px → не рисуем. Не режем треугольники в рантайме.

---

**Полигоны: сколько оставлять**

Автор моделит excess. Cooker:

- weld + degenerate kill  
- simplify до целевого **error** (не «макс 50k потому что»)  
- dense только там, где силуэт/normal cone требует  
- трава/камень: instance одного LOD-меша, не unique 1M tri  

Hard cap в импорте: warning если после simplify LOD0 > N tri (N проектный, не закон движка). Движок должен переварить 10M tri **сцены** через cull, не 10M в одном draw.

---

**RT / тени / bake из той же геометрии**

- BLAS: lod-прокси (грубый hull) для дальних; ближние — meshlet pos. Не rebuild каждый кадр NPC > 50 м.  
- OMM для masked — cooker.  
- UV2 только для Baked SG.  
- VSM рисует те же surviving meshlets, не отдельный shadow-mesh, кроме dedicated low-poly **shadow proxy** (опция арта, 1 бокс на дерево).

---

**`.bhmesh` (рантайм mmap)**

`magic BHMS | guid | hash` → 3 LOD → у каждого: meshlet meta SoA + stream A/B + uint8 idx. Порезка только в cooker.

---

**Forbidden в моделях**

Один interleaved `float3 pos + float3 n + float3 t + float2 uv` как GPU layout. 32-bit index на 64-vert meshlet. Скиннинг всего скелета до culling. CPU lock/unlock vertex buffer в кадре. Unique mesh на каждый куст. Tessellation как LOD. **Cluster DAG / runtime cut / software raster** (маркетинг Nanite). Meshlets на GPU без mesh shaders (не эмулировать task shader).

### 4.2 Куллинг — полный стек, дешёвый сначала

Порядок фиксирован. Каждый следующий работает по списку выживших. CPU occlusion query / `vkCmdDraw` на объект — forbidden.

| # | Что | Где | Зачем |
|---|---|---|---|
| 0 | **Сектор / PVS** | cooker, bitmask | интерьеры: выкинуть этаж одним AND. Опционально, огромный win в зданиях |
| 1 | **GPU scene persistent** | VRAM SoA | CPU не итерирует 100k instance |
| 2 | **Instance frustum** | compute, SIMD AABB/sphere | 90% мира |
| 3 | **Screen-size / small object** | тот же pass | < 1 px instance kill |
| 4 | **Discrete LOD** | 1 уровень на instance | без mesh shaders — на этом рисуем |
| 5 | **HZB occlusion phase 1** | depth *прошлого* кадра | дешёвый occlusion |
| 6 | **Meshlet cone** | только если mesh shaders | спина куска |
| 7 | **Meshlet frustum + HZB** | только если mesh shaders | готовые куски LOD, не DAG-cut |
| 8 | **Two-phase: depth vis → HZB 2** | всплывшие | |
| 9 | **Task/mesh inner cull** | только mesh shaders | degenerate / tiny tri |
| 10 | **Light cull** | froxel 16×16×32 logZ **или** ReSTIR | Baked/Mixed vs RTX |
| 11 | **Decal AABB vs vis/HZB** | compute | не 1000 decal на пиксель |
| 12 | **VSM page** | bbox → dirty tiles | §5.2.1 |
| 13 | **GI cell** | frustum + dirty | не обновлять весь hashmap |
| 14 | **Portal / mirror** | 2D AABB двери | опционально после PVS |
| 15 | **Skinning** | после видимости LOD/meshlet | не скиннить за спиной |

Subgroup: `ballot` + один `atomicAdd` на волну при compact, не atomic на каждый мешлет.

Occluder: сначала depth прошлого кадра. Software-occluder — если HZB врёт на решётках (§14).

**Не делаем:** иерархия `child_of` на тысячи динамических (матрицы на GPU от parent index, не CPU chain); portal как единственный cull открытого мира; CPU frustum в игровом потоке по всем entity.

### 4.3 Что с чем путать нельзя

- **Clustered lighting** ≠ deferred G-Buffer. Froxels — список ламп в объёме. Visbuffer — кто на пикселе.
- **Deferred** в 2026 = visbuffer + compute shading, не MRTs.
- **Forward+** оставляем в истории.
- Куллинг ламп (froxel) и куллинг геометрии (HZB/meshlet) — разные пассы.

## 5. Свет — красиво, быстро, RTX или дешёвый bake

Один visbuffer, один `sampleGI`, одни буферы. Bake и RTX — оба SKU навсегда. Свет может быть «как в кино» (PT bake / ReSTIR / HW rays), материалы и текстуры — painted / toon / PBR. Это микс, который Unity развалил на URP/HDRP. На старте неизвестны — кадр уже полный.

Конкуренты по свету:

| | Unreal | Unity | Мы |
|---|---|---|---|
| Дорогой realtime | Lumen | нет сопоставимого (HDRP RT) | ReSTIR + Split RC + HW отражения |
| Дешёвый bake | Lightmass / GPU Lightmass | Progressive GPU + probes | **тот же `sampleGI`, 0 лучей в кадре** |
| Смешанный | Stationary light | Mixed / Shadowmask | bake GI + VSM только на солнце |

Bake — не заглушка «пока нет RTX». Это **отдельный SKU**: инди, Steam Deck, mid-PC, сцены где лампы не ездят. Картинка статики может быть *лучше* Lumen (оффлайн PT, нет шума). Дороже по времени cooker, дешевле каждый кадр навсегда.

```
shading:
  direct = lights(kGiMode) + shadows(kShadowMode)
  gi     = sampleGI(P, N, uv2)
  spec   = reflect(kReflMode, P, N, V, r)
```

`sampleGI`: Surface SG → Split RC → Sky SH. Cooker всегда заполняет. RTX только добавляет динамику и лучи за экраном.

```
kGiMode     0 Baked     1 ReSTIR
kShadowMode 0 Baked     1 Mixed (VSM sun)    2 VSM+RTX hero
kReflMode   0 SSR       1 Hybrid             2 RTX
```

Нет `rayQuery` → Gi/Refl/Shadow RTX-слоты схлопываются в Baked/SSR. Пермутации warmup на лоаде.

### 5.0 Пресеты

| Пресет | GI | Тени | Отражения | Кадр GPU |
|---|---|---|---|---|
| **Baked** | только `sampleGI` | тень внутри SG, **нет VSM** | SSR + GI lobe + cubemap | самый дешёвый AAA-вид |
| **Mixed** | bake GI | VSM только солнце (персонаж) | SSR + GI lobe | чуть дороже, двигается солнце |
| **Hybrid** | ReSTIR 0.5 → RC | VSM + contact | SSR → короткий RTX | дефолт с RT |
| **RTX** | ReSTIR 1 spp | VSM + hero RT | HW RT primary | максимум |

Тумблеры: GI Baked|RTX, тени Baked|Mixed|RTX, отражения SSR|Hybrid|RTX. Нет caps — RTX скрыт.

Baked/Mixed работают на любой Vulkan-карте 2022+. Это ответ Lightmass, не «слабый режим».

| Существует | Берём | Не берём |

| ReSTIR DI/GI | лучший realtime при 0.5–1 spp | PT как кадр игры |
| Frostbite SG | bake статики | RGB lightmap как единственный свет |

### 5.2 Прямой свет и тени (пресеты)

| Пресет | Прямой | Тени |
|---|---|---|
| **Baked** | уже внутри SG (cooker PT) | shadow mask в SG. **VSM выкл.** 0 shadow pass |
| **Mixed** | GI из bake; солнце realtime | VSM dirty на динамику/ближнюю зону; вдали mask |
| **Hybrid/RTX** | ReSTIR DI | VSM весь кадр (только dirty pages) + optional hero `rayQuery` |

Полный Baked: минус ReSTIR, минус VSM, минус BLAS. Visbuffer + 2–3 fetch кэша.

---

### 5.2.1 Тени — самое дешёвое, что в 2026 ещё выглядит как кино

Жёсткая тень ≠ GI и ≠ ReSTIR. Отдельный бюджет. Лучшее железо 2026 для солнца на открытом мире — не «4 каскада CSM каждый кадр» и не RT по каждому листу.

**Realtime солнце / большие лампы → Virtual Shadow Maps (как UE5), не CSM.**

| Правило | Зачем |
|---|---|
| Атлас страниц **128×128** (клипмап вокруг камеры) | бесконечная дальность без 4 каскадов |
| Физическая память только у видимых страниц (sparse) | пустой лес за холмом = 0 VRAM |
| **Dirty-only:** сфера объекта → страницы; static без `TransformChanged` не рисуется | главный выигрыш vs CSM |
| Растр в страницу: meshlets + HZB, тот же visbuffer-путь | не второй геометрический пайплайн |
| Сэмпл: 1 tap + **SMRT** (2–8 шагов по mip VSM) | мягкий край контакта без PCSS 16 tap и без RT |
| Contact 1–2 шага по depth | щель у ног, VSM это смазывает |
| Capsule из костей | толпа, 0 shadow-полигонов |
| Локальные лампы | 1 VSM-атлас на **важные** spot/point; остальные — baked mask или clustered без тени |
| Hero `rayQuery` тень | только персонаж/оружие в пресете RTX. Трава, дебрис, листва — VSM или mask |
| Foliar: OMM если RT hero; иначе mask/dither, не 6 cubemap | |

**Не берём как primary:** классический CSM 4 каскада каждый кадр, PCF 5×5, cubemap point light на каждую лампочку, RT-тени мира, SDF-тени как единственные (только fallback без sparse).

**Baked тени (самые дешёвые):**

Cooker PT пишет **shadow mask** (R8 или альфа SG): солнце и статичные лампы. В кадре 1 fetch, acne нет. Distance Shadowmask: ближе N метров (Mixed) — VSM на муверов, дальше — mask. Это Unity/UE Stationary, у нас те же буферы.

GPU bake теней: те же лучи, что GI (один PT), не отдельный «shadow baker». Texel validity / dilation — в cooker, иначе швы UV.

Итог по оптимизации: Baked = 0 pass. Mixed = VSM только dirty near. Hybrid = VSM dirty всего солнца (статика всё равно почти 0). RTX = +1 луч на hero, не на мир.

---

### 5.3 GI realtime vs GI baked

Память одна (SG + Split RC). Писатель разный.

**Baked / Mixed GI:** 0 HW лучей в кадре. `sampleGI` = класс Lightmass. Игрок и пропы без UV2 берут **volume RC** (как Unity Light Probes / Unreal Volumetric Lightmap), те же ячейки, что читает RTX.

**ReSTIR:**
```
visbuffer → ReSTIR GI (0.5 Hybrid / 1.0 RTX spp)
  temporal + 4 neighbor
  вторичный хит: sampleGI(), не 2-й луч
  1 rayQuery visibility
  → SVGF + blend dirty RC
```
Мир стоит → лучи можно выключить, кадр становится Baked на уже заполненном RC.

---

### 5.4 Отражения — SSR, RTX, или оба

Даже **Baked** не чисто SSR: промах → specular lobe из SG/RC → cubemap.

| `kReflMode` | |
|---|---|
| **SSR** | HZB-SSR → miss → `sampleGI` lobe → cubemap. С Baked это полный дешёвый стек. |
| **Hybrid** | + 1 HW ray если miss, r<0.35, dist<20 м |
| **RTX** | HW ray primary; `SSRAssist`; r≥0.4 → кэш |

Можно Baked GI + RTX отражения (зал запечён, лужи живые).

---

### 5.5 Запечённый свет — дешёвый SKU (конкурент Lightmass)

Цель cooker: **GPU path trace один раз**, выход сразу в рантайм-буферы. Ориентир по скорости: GPU Lightmass / Unity Progressive GPU, не час CPU.

Что печём, чтобы Baked был кино, не серый ambient:

| Слой | Формат | Кто читает | Зачем дешевле realtime |
|---|---|---|---|
| Direct+GI статики | 1–3 SG или L1 SH на UV2, BC6H+BC5 | стены `sampleGI` | 1–2 fetch вместо ReSTIR+SVGF |
| Shadow mask | R8 / альфа SG | Baked тени | **нет VSM** |
| Volume муверов | Split RC ячейки, SH | персонаж, проп, VFX | не UV2 на героя |
| Bent normal + AO | `.bhmesh` | все пресеты | щели без GTAO |
| Specular bake | SG lobe + cubemap по зонам | miss SSR | интерьер без HW RT |
| Sky | cubemap + SH | все | бесконечность |
| GSDF | R8 блоки | optional no-RT march | запас |

Качество cooker (не три движка):

| | Fast | High | Cine |
|---|---|---|---|
| spp | 32–64 | 256–512 | 2k+ |
| UV2 | ~15 px/m | ~50 | 100+ |
| RC | редко | плотнее у спавна | плотно |

**Mixed** — чуть дороже Baked, сильно дешевле Lumen:

- статика: GI+тени из SG;
- солнце: VSM на динамику/ближнюю зону, вдали mask (Distance Shadowmask);
- локальные лампы: baked если стоят, иначе clustered без ReSTIR;
- день/ночь без RTX: 2–4 bake, lerp тех же SG.

Bake не умеет: едущая фара, ломающийся уровень, живое небо каждый кадр → Mixed или RTX.

Сдвинул light в редакторе → GPU PT **сектора**, не мира. В кадре игры Baked ничего не печёт.

Цена кадра (порядок):

| | Baked | Mixed | Hybrid | RTX |
|---|---|---|---|---|
| Лучи | 0 | 0 | ~0.5 spp | 1 spp + refl |
| Shadow pass | нет | VSM dirty | VSM | VSM + hero |
| Таргет | Deck / weak 1080p60 | 1080p144 | 1440p | 4K RT |

### 5.6 Денойз / dirty

ReSTIR и RTX-отражения → SVGF. Baked lookup → без денойза (стабильнее Lumen).

| Событие | Baked | Mixed | Hybrid/RTX |
|---|---|---|---|
| Поворот камеры | SSR | SSR | + ReSTIR screen |
| Ходьба | 0 | VSM если dynamic | ReSTIR visible |
| Лампа в редакторе | rebake сектора | rebake GI | лучи |
| Idle | shading | shading | 0 лучей |

Сборка: M2 sun+SSR → M6 VSM (Mixed) → M7 **Baked SKU готов** → M8 ReSTIR/RTX.

### 5.7 Сводка

| | Baked | Mixed | Hybrid | RTX |
|---|---|---|---|---|
| Прямой | в SG | sun VSM + bake GI | ReSTIR DI | ReSTIR 1 spp |
| Тени | mask | VSM near + mask far | VSM | VSM + hero |
| GI | SG+RC | SG+RC | ReSTIR→RC | то же |
| Отражения | SSR+SG | SSR+SG | SSR→RT | RT primary |

## 6. Entity — Flecs + DoD

Почему Flecs, не свой `class Entity` и не массив объектов: архетипы = **SoA колонки**, системы бегут по плотным массивам (SIMD/кэш). Это быстрее типичного OOP ECS (`virtual Update`, `vector<GameObject*>`). EnTT тоже DoD, но Flecs даёт теги, relationships, cached query, observers — один стек. **Второй ECS запрещён.**

Идентичность: `uint64_t` GUID (MurmurHash3), в рантайме **32-bit handle** в колонку. Указатель на entity forbidden.

### 6.1 Данные (горячее / холодное)

| Колонка | Где | Кто пишет |
|---|---|---|
| `Transform` (pos/rot/scale float, `alignas(16)`) | hot SoA | Jolt или логика |
| `TransformHistory` {current, previous} | только **Dynamic** | для GPU motion / интерполяции |
| `WorldBounds` sphere/AABB | hot | dirty-система |
| `GpuHandle` (instance index) | hot | сцена |
| `Static` / `Active` / `TransformChanged` / `PhysicsHigh|Med|Low` | теги, 0 байт | системы |
| Имя, слой редактора, GUID-строка | **cold**, не в кадре | editor |

`Static`: нет History, нет physics step, нет записи в ReBAR каждый кадр, GPU instance живёт в mmap/upload раз. `Dynamic` замирает (`current == previous`) → снять High, как sleep; удар/скрипт будит.

Иерархия: `child_of` только для редакторских групп / скелета костей, **не** тысячи динамических с CPU matrix chain. World matrix — compute из parent index на GPU, если нужна.

### 6.2 Системы

- Кэшированный `flecs::query<...>` (static / построен раз), free-function systems.
- Итерация: указатели на колонки / `flecs::field`, не `GetComponent("Transform")`.
- `add`/`remove` **не** внутри итерации → `defer` / command buffer, сдвиг архетипа в конце кадра.
- `ecs_changed` / тег `TransformChanged`: писать GPU и будить VSM/GI только по dirty чанкам.
- Нет `virtual` на системах, нет `std::function` в горячем списке (таблица указателей на free fn ок).
- Потоки: Flecs + Taskflow; один мир, structural changes с главного/deferred. Не mutex вокруг query.

Связь с GPU: система `SyncTransforms` читает dirty SoA → packed 12B/instance в **ReBAR**. Не `memcpy` всех 100k. Physics пишет в ту же колонку `Transform`, рендер не зовёт Jolt.

Связь подсистем: только POD в thread-local очередь (контакт → звук `{hash, pos, speed}`). Physics → Audio прямым вызовом forbidden.

### 6.3 Спавн / пулы

Тела, пули-трассеры, декали — **пулы** (TLSF / arena). Не `world.entity()` в взрыве без reserve. Пули: визуальный entity **без** RigidBody.

Forbidden entity: `shared_ptr<GameObject>`, дерево компонентов-классов, string lookup, entity pointer в компоненте, deep hierarchy на мобе.

## 7. Физика — Jolt

Один движок: **Jolt**. Не Bullet/PhysX рядом. Float32 + **floating origin** (мир едет за игроком). Double Precision не включаем.

Job: `JPH::JobSystem` → те же fibers/Taskflow, `FrameArena` как temp allocator. **Не** фиксированный step на render thread. Кадр N: physics; GPU читает предыдущий `TransformHistory`.

### 7.1 Слои и тиры (главная оптимизация)

Слои: `NON_MOVING`, `MOVING`, `DEBRIS`, `SENSOR`, `PROJECTILE`. DEBRIS×DEBRIS выкл.

| Тир | Частота | Кто | Тег Flecs |
|---|---|---|---|
| High | каждый physics tick | игрок, враги в бою | `PhysicsHigh` |
| Medium | 15–20 Hz | декор, дальний NPC | `PhysicsMedium` |
| Low | 2–3 Hz | обломки, триггеры | `PhysicsLow` |
| Sleep | 0 | \|v\| < ε | нет Active |
| Distance | broadphase off | далеко от камеры/игрока | снять из симуляции |

Смена тира — тег Flecs. CCD только `PROJECTILE` (лучше hitscan). Ткань/волосы — §14, после culling; >30 м rigid proxy.

**Пули:** в момент выстрела батч `NarrowPhaseQuery` raycast, не сфера-коллайдер. Трассер — mesh instance без Jolt.

### 7.2 Тела и запись в кадр

- Статика уровня: `NON_MOVING`, cooker convex/mesh collision, не unique mesh collider на камень без нужды (simplified hull).
- Динамика: пул `BodyID`. Спавн = take from pool, не `CreateBody` в горячем взрыве без пула.
- Character: `CharacterVirtual` (лестницы, платформы).
- Результат шага: Jolt → колонка `Transform` + `TransformChanged` → ReBAR. GPU interpolation из History. Нет копии через staging «на всякий».
- Raycast геймплея: батч за кадр. VFX — SDF/GPU (§14), не sync raycast на каждый спрайт.
- Debug: DrawIndirect линии, не CPU mesh на каждый collider в кадре игры.

### 7.3 Чего не делать

Jolt с render thread. DP «для больших миров» (origin дешевле). Коллайдер на пулю. CCD на всех. `memcpy` всех body в VkBuffer. Physics.Update в том же потоке, что visbuffer. Тысячи active debris без sleep. Детерминизм через запрет FMA на всём GPU (если сеть — отдельный milestone, fixed-point/Jolt determinism flag, не DP).

## 8. Как устроен движок внутри

Не граф объектов. Три канала данных:

| Канал | Что | Пример |
|---|---|---|
| **SoA / Flecs** | симуляция кадра N | Transform, теги, Jolt BodyID |
| **GPU buffers (BDA / ReBAR)** | то, что читает шейдер | packed instance, meshlets, heaps |
| **POD event** | между модулями, lock-free | `{guid, pos, speed}` контакт → аудио |

Модуль **не** вызывает другой модуль (`physics.playSound()`). Пишет POD в thread-local очередь; gather раз в кадр.

### 8.1 Владельцы

| Данные | Владелец записи | Читатели |
|---|---|---|
| input | platform | game, camera |
| Transform | Jolt или game (не оба в один кадр на entity) | GPU sync, vis |
| BodyID | physics пул | только physics |
| GpuHandle / packed TRS | world sync (dirty) | culling, vis, VSM |
| visbuffer / HZB | render | shading, SSR |
| sampleGI кэш | cooker + ReSTIR | shading, reflections |
| VSM pages | shadow pass | shading |

Конфликт записи = баг. Два писателя в Transform — запрет (один authority).

Объект в мире = GUID + handle в колонки + опционально GpuHandle. Нет `class MeshRenderer : public Component`.

### 8.2 Кадр (кто когда работает)

```
главный поток + workers:
  Frame N:   input → Flecs systems → Jolt (High/Med/Low) → dirty bits → packed ReBAR
  Frame N-1: GPU cull, skinning visible, VSM dirty, ReSTIR, record/DGC
  Frame N-2: GPU execute, present_wait
```

Timeline semaphore будит CPU на present. Не `sleep_for`. Не ждать fence «весь GPU» если можно split event.

Аллокации: **init/load** = TLSF/mimalloc/VMA. **Кадр** = FrameArena reset. Игра не `new` в Update.

I/O: mmap `.bh*` / io_uring|DirectStorage в DMA queue. Не `ifstream` в системе кадра.

### 8.3 Как добавить фичу

1. Данные: POD / колонка / GPU struct (std430, 16B).  
2. Кто пишет, кто читает, **dirty**.  
3. Нет — фича не мержится.  
4. Шейдер: heap index в push constants, не новый descriptor set layout «на эффект».  
5. Живёт в **своём модуле** (§2.1), не в `Main` и не в `Device.cpp`.

## 9. Стандарт кода

**Язык:** `-std=c++2c`. Кадр: POD, `span`, `mdspan`, `bit_cast`, `enum class : uint8_t`, `alignas(64)` на очередях. Init/load: `std::expected`, не исключения в loop.

**Имена:** `PascalCase` типы, `camelCase` функции, `k` константы, `g_` только кэш query. Файлы = модуль (`world/Transform.h`, не `Utils/Helpers2`).

**Компонент:** `struct Transform { ... }; static_assert(std::is_trivially_copyable_v<Transform>);` Concept `Component<T>`.

**Горячий путь (query, physics, record):**

- нет `virtual`, RTTI, `shared_ptr`, `string`, `format`, `function`, `vector::push_back` без reserve  
- нет `mutex` между модулями  
- нет путей `"textures/x.png"` — GUID  
- ветка: предсказуемый `if (isStatic)` ок; непредсказуемое → маска/`cmov`  
- SIMD: колонки SoA, код без скрытого pointer chase  

**Холодный путь (cooker, editor, init):** spdlog, simdjson, `std::vector` с reserve — можно.

**Ошибки:** кадр — коды/assert debug. Load — `expected`. GPU fault — не глотать `vk*` без check на init.

**Комментарии:** зачем dirty/барьер, не «increment i». Не писать роман.

Перед PR: чеклист §1 + «кто пишет эти байты».

## 10. Vulkan 1.4 — как писать код

Цель: **1.4 core + выбранные EXT**, не зоопарк 2018. Один стиль на весь `rhi/`.

### 10.1 Объекты, которых нет в архитектуре

| Старое | Вместо |
|---|---|
| `VkRenderPass` / `VkFramebuffer` | `VK_KHR_dynamic_rendering` (+ local_read где нужен feedback) |
| `VkPipeline` | `VK_EXT_shader_object` (`vkCmdBindShadersEXT` + dynamic state) |
| `VkDescriptorSet` / pool | `VK_EXT_descriptor_heap` + BDA; нет heap на девайсе → **один** bindless array, не три системы сразу |
| `vkCmdDraw` на CPU-списке объектов | indirect count / DGC; debug `--use-classic-indirect` |
| `vkQueueSubmit` на каждый compute | один batch на очередь в кадр |
| `vkAllocateMemory` в кадре | VMA пулы, ReBAR `DEVICE_LOCAL\|HOST_VISIBLE` write-only |
| Монолитный `vkCmdPipelineBarrier2` на весь кадр | `vkCmdSetEvent2` producer + `vkCmdWaitEvents2` consumer. Barrier2 — узкий, на один ресурс |
| `vkCreateShadersEXT` в геймплее | warmup на лоаде: **мало** spec-пермутаций (качество + 2–3 feature), не комбинаторика нод |

Volk — все функции. Caps **один раз** при `vkCreateDevice`: таблица `DeviceCaps { meshShader, rayQuery, descriptorHeap, dgc, ... }`. Код: `if (caps.meshShader)`, не `#ifdef NVIDIA`.

### 10.2 Канон кадра RHI

```
queues: Graphics REALTIME | Compute HIGH | Transfer MEDIUM
sync:   timeline semaphore (кадр N) + present_wait + present_id
CB:     ONE_TIME_SUBMIT или DGC; пулы reset, не вечный reuse без правила
bind:   vkCmdBindResourceHeapEXT (+ sampler heap) раз на CB
        push constants ≤256B: camera, heap indices, time — не UBO «на всё»
draw:   visbuffer = mesh tasks ИЛИ DrawIndexedIndirectCount
        shading = compute, тот же heap
```

Изображения: dynamic rendering `VkRenderingInfo`, layout через barrier/event, не subpass. Swapchain: HDR10 → scRGB → SDR, mutable format если caps.

Буферы: `SHADER_DEVICE_ADDRESS`, шейдер `buffer_reference` / heap index. CPU пишет только mapped ReBAR или staging ring **write-only** (не читать upload heap обратно).

Шейдеры: **только код**. Порядок предпочтения: **Slang** (модули, generics, меньше register pressure) → HLSL → GLSL. Все в SPIR-V 1.6+ / shader objects. Нет Shader Graph / Blueprint / нод Blender → SPIR-V.

**Авторство (удобно, без мусора):**

1. **Пресеты движка** — оба столпа: **PBR / Skin / Hair / Glass / Foliage** (реализм) и **Toon, Unlit, Matcap, Pixel, VertexColor, Outline** (стиль). Один SPIR-V на пресет, не на ассет.
2. **Свой шейдер** — человек пишет `.slang` / `.hlsl` / `.glsl`. Cooker компилирует **один** SPIR-V + **схему параметров** (reflection: имена, типы, диапазоны, группы).
3. **Inspector** — вкладки/слайдеры/слоты текстур **появляются из схемы**. Художник крутит значения, не рисует ноды. UI не генерирует код.
4. **Instance** = GUID шейдера + POD params + heap indices текстур. Тысячи инстансов, **один** compiled shader.

Permutations = меню качества + 2–3 feature (`kGiMode`, masked…). Warmup на лоаде. Не комбинаторика нод.

`nonuniformEXT` на bindless. `textureLod` в ветках. `demote` не `discard`. Reflection SPIR-V → оффсеты POD / heap.

### 10.3 Запреты Vulkan-кода

Классические sets + descriptor_buffer + heap в одном кадре. Render pass. `vkWaitIdle` в loop. CPU readback visbuffer каждый кадр (picking — раз по клику, не 60 Hz). Два ALU-compute на одних CU без профилирования. Validation выкл. в debug. Хардкод очереди `familyIndex = 0`.

Новый pass: имя в render graph (transient image + event wait). Не «ещё один `vkCmdPipelineBarrier2(ALL_COMMANDS)`».

## 11. UI — Yoga + GPU 2D, без ImGui

Один стек на **редактор и игру**. ImGui не линкуем. Yoga — только **layout** (flexbox, как CSS). Виджеты (кнопка, панель, дерево сцены) — наши, retained. Рисование — GPU, не 500 `vkCmdDraw`.

### 11.1 Кадр UI

```
dirty layout? → Yoga calculate (дерево нод, не каждый виджет «с нуля как ImGui»)
dirty visuals? → записать UIPrimitive[] в SSBO (только изменённые)
GPU: 1 DrawIndirect (или compute quads) на слой: panel / popup / hud
3D сцена → UI поверх, UI всегда native res (3D может скалироваться)
```

Layout **не** каждый кадр, если дерево и размеры не менялись. Счётчик/HP: менять текст/прогресс без полного Yoga, если бокс тот же.

### 11.2 Примитивы (SSBO, POD)

```
struct UIPrimitive { // 64B, std430
  vec2 pos, size;     // после Yoga
  vec4 color;         // sRGB/linear по контракту
  uint texId;         // heap: 0 = solid/roundrect, иначе атлас
  uint flags;         // rounded, sdf, glyph, clip
  vec4 extra;         // radius, uv, sdf range, glyph id
};
```

Шейдер: round-rect + SDF в FS/compute, клип AABB в шейдере (не `vkCmdSetScissor` на кнопку). Слои: z-order + stencil/mask bit.

Текст: **MSDF** атлас (cooker / msdfgen), не FreeType в кадре. Глифы = те же примитивы. CJK/араб: HarfBuzz **на dirty текста**, результат в кэш глифов; не shaping 60 Hz на статичную строку.

Иконки/кнопки: атлас в heap, не отдельная текстура на виджет.

### 11.3 Ввод

Hit-test по **уже посчитанным** Yoga box на CPU (сотни нод, не GPU readback). Hover/press → dirty только этой ноды. Игра: HUD ест клик; если мимо — в world (visbuffer pick по клику, не каждый кадр).

### 11.4 Редактор vs игра

Тот же `ui::Renderer`. Разные **деревья**: `editorRoot` (доки, иерархия, инспектор) и `gameRoot` (HUD, меню). Play-in-editor: gameRoot в viewport, не второй ImGui.

Доки: flex column/row + split handles (сами), не ImGui docking. Нативный file open = nfd.

### 11.5 Запреты UI

ImGui / Nuklear / Qt в рантайме. `Begin("Button")` каждый кадр как единственная модель. Текстура на каждую кнопку. CPU tessellate bezier 60 Hz (вектор — SDF/MSDF). Yoga в hot path физики. UI вперемешку с 3D без слоя. Rive вместо Yoga (Rive — только authored motion, §14).

## 14. Полный продукт (после ядра, тоже закон)

Не «потом придумаем». Когда фича входит в шип — только эта колонка. **Сейчас не пишем:** волосы, океан, сеть, TSR/FSR, destruction — месяцы/годы после M10. Закон нужен, чтобы не появился второй пайплайн. Порядок: M10, потом сверху вниз **по нужде игры**. Всё в те же heap / `sampleGI` / Flecs / Yoga.

| Система | Лучшее решение | Не делать |
|---|---|---|
| Прозрачность | OIT: `fragmentShaderInterlock` или weighted blended + `demote` в masked; сорт на GPU/слои, не CPU | CPU sort всех партиклов |
| Частицы | compute, фиксированный пул, indirect; коллизии — baked SDF | readback count на CPU |
| Волосы / мех | guide XPBD + mesh shader ribbons; shading Marschner; TSS если дорого каждый пиксель | CPU hair, RT на каждую прядь |
| Ткань | XPBD compute, тайлы LDS; после HZB — freeze culled; >30 м rigid | SoftBody на весь зал |
| Океан | FFT displacement + froxel fog; Jolt impulses на поверхность | realtime gerstner на CPU |
| Объём / небо | froxel 3D + LUT атмосфера; облака 1/4 res + temporal | полный ray march 1080p без upsample |
| Impostor / HLOD | после LOD2, карты/билборд cooker | Gaussian splat как default distant |
| SVT / стриминг текс | 64–128 px tiles, sampler feedback если caps; до этого полные mips | runtime parse PNG |
| Occluder extra | software depth 64px если HZB врёт на сетке | второй полный raster мира |
| Аудио | miniaudio + DSP graph SIMD; контакт Jolt = POD; bake IR; RT audio — micro ray в voxel только High | decode Opus на render thread |
| Навмеш | Recast cooker, Detour runtime; GPU RVO local; SDF vision не raycast AI | A* каждый кадр на агента |
| Сеть | later milestone: bitsery + jitter; Jolt determinism flag, не DP | rewind полного мира memcpy |
| Скрипты | WASM sandbox после стабильного ECS; хуки в колонки, не virtual BT | Lua в hot path на каждый entity |
| Вектор-аним UI | Rive **только** motion clips; layout всё равно Yoga | Rive вместо flex |
| Work graphs / DGC chain | `if (caps)` на тот же cull | обязательный AMD-only путь |
| Destruction | ID swap table + compound Jolt из пула | runtime Boolean на всех мешах |

Neural GI / semantic search ассетов — не ядро продукта, не блокируют §14.

## 15. Чего ещё не было в законе (и как делаем)

Ядро рендера/света/физики/UI закрыто. Ниже — дыры **игрового движка**, без которых нет шипа. Это тоже закон, не бэклог «подумаем».

### 15.1 Ввод, камера, время

| | Решение | Не |
|---|---|---|
| Ввод | SDL3 events → POD `InputFrame` (кнопки битмаска, оси f32). Ребинд = таблица GUID действий. Late-latch камеры в push constants перед submit | `GetKey` по строке в системах |
| Пад / вибрация | SDL haptic из POD (impactSpeed с Jolt) | отдельный поток-сон |
| Камера | spring-damper + Jolt sphere cast (не в стену); FOV/экспозиция из физического набора; motion vectors из History | камера в ImGui |
| Пауза / timescale | `world.timeScale` на логику и Jolt; рендер и UI 1.0 | `sleep` кадра |
| HDR / окно | Yoga в **pixels окна**; 3D может быть 50–100% res (PID по GPU time); UI не скалировать вместе с 3D | HUD в visbuffer |

### 15.2 Анимация

Не только skinning после cull.

| | Решение |
|---|---|
| Рантайм | Ozz (DoD) или свой SoA клипов в `.bhanim`; CPU только state (speed, tag), кости — GPU dual-quat |
| Клипы | 3 набора как меш: не 200 слоёв blendtree. Inertial blend (velocity) вместо crossfade-матриц |
| Root motion | дельта в Transform, согласована с Jolt Character (не телепорт) |
| IK | compute, 1–2 кости (ступня), normal из depth/SDF; не Full Body IK на всех |
| Рэгдолл | Jolt motors на `.bhbone` лимиты; LOD: далеко = anim only |

### 15.3 Материалы, декали, пост

Материал = **шейдер (код) + instance (данные)**. Редактор удобный; SPIR-V не плодится.

| | Решение |
|---|---|
| Пресеты | реализм: PBR, Skin, Hair, Glass, Foliage, Terrain. стиль: ToonRamp, Unlit, Matcap, Pixel, VertexColor, Outline, Masked, Decal, UI |
| Свой шейдер | `.slang` (предпочтительно) / `.hlsl` / `.glsl`. Пишет программист. Cooker → 1 SPIR-V + `MaterialSchema` |
| Inspector | вкладки из `[[ui(group=...)]]` / атрибутов reflection: Color, Slider, Texture2D, Toggle. **Не** граф нод |
| Instance | `.bhmat` = shaderGuid + POD + texture GUIDs. Смена albedo не компилирует шейдер |
| Uber vs custom | пресеты шарят модули Slang (`sampleGI`, shadows, visbuffer unpack). Custom **включает** те же модули, не копипастит свет |
| Feature | spec constants / bitmask, не `#ifdef` и не новый файл на каждый toggle |
| Запрет | Shader Graph, Blueprint, «Bake nodes to HLSL», уникальный SPIR-V на каждый материал сцены |

Данные шейдера (для UI и runtime):

```
MaterialSchema {  // cooker, один раз на .slang
  param[] { nameHash, type, offset, uiGroup, min, max, default }
  texture[] { nameHash, dim, uiGroup }
}
MaterialInstance {  // .bhmat, много
  shaderGuid, paramBlob[], texHeapIndex[]
}
```

Художник: **свет** (Baked/Mixed/RTX) отдельно от **материала** (toon albedo на ReSTIR — норма). Look крутит пост/ramp/AgX, не ломает GI.

**Look (не второй рендер):** один POD. Реалистичный свет + стилизованные карты — тот же visbuffer / `sampleGI`.

```
LookSettings {
  shading   // RealisticPBR | StylizedPBR | Toon | Unlit | Matcap | Pixel
  outline   // 0 или visbuffer id/depth edges
  rampTex, bands, specCut
  palette, dither, crush
  fog, grade, AgX   // свет RTX/bake не зависит от AgX
  giStrength, shadowTint
}
```

Нет toon-движка и нет «RTX-движка». Toon-материал читает тот же `sampleGI`.

| | Решение |
|---|---|
| Декали | D-Buffer / visbuffer id + проекция в shading; clip по meshlet AABB | не 1000 forward decal |
| TAA / векторы | обязательны для ReSTIR/SSR; History уже есть |
| Апскейл | FSR/XeSS/DLSS **если SDK**, иначе свой TSR; UI после апскейла |
| Цвет | linear. Realism: AgX + HDR10. Style: grade/palette/dither, AgX выкл. Один пост-стек |
| Motion blur / DoF | compute, tile skip; не в Uber если бюджет |

### 15.4 Мир, сейв, префабы

| | Решение |
|---|---|
| Секторы | `.bhscene` куски + PVS bitmask; грузить mmap/io_uring по камере |
| Prefab | `.bhpfab` = GUIDs + SoA override; instance не копия меша |
| Сейв | XOR/delta журнала компонентов + GUID; не JSON мира, не полный memcpy scene |
| Undo редактор | тот же journal, не копия entity |
| Версия ассета | guid + contentHash; hot-reload xxHash, не путь |
| Cook graph | зависимости в header файла; перепечь сектор, не всё |

### 15.5 Террейн, растительность, погода

| | Решение |
|---|---|
| Ландшафт | clipmap / virtual heightfield, те же 3 LOD+meshlets cooker, не tessellation pipeline |
| Трава | instance одного меша + HZB; ветер — compute offset, не unique mesh |
| Погода | GVF ветер 3D tex; осадки meshlets; туман = froxel §14 |
| Триггеры | Jolt SENSOR + тег Flecs; не Update() на каждый volume |

### 15.6 ИИ, геймплей-каркас

Навмеш уже §14. Добавить:

| | Решение |
|---|---|
| Поведение | data-driven таблица/GOAP bitmask или пачка FSM на 64 агента/wave; не virtual BehaviorTree |
| Perception | SDF / visbuffer id, не raycast на агента каждый кадр |
| Hit / damage | POD события, не `enemy->TakeDamage()` виртуальный |

Сетка инвентаря/квестов — **игра**, не движок (скрипты WASM читают колонки).

### 15.7 Редактор, тесты, шип

| | Решение |
|---|---|
| Пикинг | visbuffer readback **по клику**, не 60 Hz |
| Gizmo | Yoga overlay + GPU линии; манипулятор пишет Transform напрямую |
| Gold-frame | SSIM на CI, 2 GPU если можно; не bit-identical |
| Shader reload | versioned heap slot, atomic BDA swap; не recreate device |
| Профиль | Tracy + GPU timestamps на pass; adaptive: VRS / ReSTIR M / shadow dist |
| Локаль | ID строк uint, таблица в cold; не `u8"Привет"` в системах |
| Доступность | цветовой фильтр в Uber-post; UI scale Yoga |
| Платформы | Win64 + Linux64; Deck как Linux | консоли, VR, mobile |
| Крах | robustness2 + recreate device | глотать device lost |

### 15.8 Не делаем

VR/AR, мобильный GLES, консоли как цель, Win32, магазин ассетов, нейро-поиск, полный USD runtime, браузер в движке, второй ECS для UI. Кнопки ≠ 100k мобов в одном архетипе. Не цель старта — имя UE. Цель — **Unity, которым он не стал:** стилизация + реалистичный свет, удобно инди, WASM вместо C#/GDScript/игрового C++.

## 16. То, что есть в 99% игр (примитивы движка)

Игра на WASM + колонки. Движок даёт **системы и данные**, не готовый шутер. Без этого набора почти ни одна игра не собирается.

| Нужно в игре | Примитив движка |
|---|---|
| Меню, пауза, настройки графики | Yoga; `kGiMode/kShadow/kRefl` + Look (outline/ramp/palette) + res/VRS |
| Игрок ходить/смотреть | Jolt CharacterVirtual + камера §15.1 + InputFrame |
| Нажать E, подобрать | SENSOR/overlap + POD interact; луч из камеры batch |
| Урон / хп | POD `Hit{guid, dmg, pos}`; нет virtual TakeDamage |
| Спавн врагов/итемов | пул entity + `.bhpfab` |
| Дверь, лифт, проп с анимацией | клип Ozz + Jolt kinematic; root motion согласован |
| Чекпоинт / сейв | journal GUID §15.4 |
| Загрузка уровня | mmap сектора + loading Yoga; не JSON parse |
| HUD, миникарта | gameRoot Yoga; миникарта = depth/id downsample, не второй мир |
| Субтитры, локаль | ID строк + таблица |
| Настройки звука | DSP graph gain; 2D UI / 3D world |
| Гром / шаг / удар | POD от анимации/Jolt → аудио |
| Триггер тумана, киллзоны, реверб | volume = SENSOR + cold params |
| Катсцена | timeline: камера-сплайн + lock input + anim; не видео 4K в движке |
| Сплайны (рельсы камеры, путь) | `.bhspline` cooker (Blender curve) |
| Вода «зашёл — плыву» | volume + buoyancy Jolt, не полный океан |
| Навмобы | Detour + FSM §14–15 |
| Инвентарь / диалог / квест | **WASM** + SoA таблиц; движок — слоты данных и UI биндинг |
| Геймпад по меню | Yoga focus ring; не мышиный-only |
| Loading / credits | Yoga; кредит = текст ID |

Мультиплеер **потом**, но API сейчас: нет скрытых синглтонов «текущий игрок»; весь стейт в колонках GUID; ввод = `InputFrame` на pawn. Когда сеть: bitsery снапшоты, Jolt determinism flag, не DP, не full-world memcpy.

WASM: хост = `get/set` колонка по GUID, spawn prefab, queue POD. Модуль без `malloc` в hot tick (арена с хоста). Не интерпретатор на каждый entity.

Это ответ на чужие дыры: Unity C# (GC, домен, версии runtime), Godot (свой язык / свой VM), Unreal (геймплей на C++ движка). Игра на WASM, движок на C++26. Один ABI, любой язык, который компилируется в wasm32.

## 17. Фишки Blender, которых нет в типичном движке — берём

Не скульптинг и не VSE. Берём **пайплайн данных**, который в UE/Unity обычно боль или плагин.

| В Blender | У нас |
|---|---|
| Collections / outliner / view layers | редактор: дерево GUID + visibility bitmask; не 1000 `child_of` в кадре |
| Collection instance | GPU instance + prefab override (library override) |
| Geometry Nodes scatter | **cooker** → instance buffer / `.bhpfab`; не Houdini в игре |
| Modifier stack (array, curve deform, remesh) | только cooker → 3 LOD meshlets |
| Shader nodes (Blender) | **не импортируем**. Пресет/свой `.slang` + inspector из reflection; художник крутит params | граф → тысячи SPIR-V |
| Shape keys | GPU morph target, 4–8 целей, после culling |
| Color / density attributes | stream C в `.bhmesh` (грязь, маска травы) |
| Weight / vertex paint | bake в stream, не кисть в рантайме игры (в редакторе — optional) |
| Curves as objects | `.bhspline` для камеры/IK/path |
| NLA strips | cinematic timeline, не 50 слоёв на мобе в бою |
| Drivers | cooker bake кривой или WASM на GUID |
| Light linking (4.x) | битмаска «какие лампы видят meshlet»; ReSTIR/cluster читает маску |
| Cryptomatte / AOV | visbuffer id + debug AOV в редакторе |
| AgX / color mgmt | уже пост AgX |
| Grease pencil | аннотации редактора MSDF-штрихи; не GP как игровой рендер |
| Asset catalogs | GUID + теги, не нейропоиск |
| Linked .blend | как linked prefab: дельта override, не копия меша |
| Geometry Nodes sim bake | VAT / кэш в cooker, 0 CPU сима в кадре |
| Boolean / voxel remesh | cooker; не runtime CSG |
| Pose library | клипы `.bhanim` |
| World / sky nodes | sky cubemap + SH bake |
| Light probes | наши RC/SG |
| Custom properties | cold ECS / WASM tables |
| Face maps / material slots | 1 материал на meshlet |

Не тащим из Blender: скульпт как игровой режим, Video Sequencer, motion tracking, VR viewport, полноценный Cycles в рантайме (Cycles/PT = **cooker bake**).

Импорт: Blender → glTF/USD-lite/наш exporter в cooker. Не встраиваем `libblender` в игру.
