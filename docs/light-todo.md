# Свет — контракт, пока не закрыт

Временный файл. Строка уходит, когда кусок собран и линкуется. Модуль — свои данные и своя запись, без базового класса. Общая математика — `camera.slang` и `engine/render/core/`. Ядро не знает имён шейдеров сцены. На горячем пути кадра нет `vector` и `new`. Луч не печёт BLAS в буфере, который ждёт холст. Один диспатч ray query после shade допустим: сцена кончает раньше холста.

Профили на панели работают. `PassFlags.lightProfile`: 0 низкий, 1 баланс, 2 ультра. Бит 128 ставится только на 1 и 2.

ReSTIR не пишем, пока нет своего денойзера. Ультра пока читает Split RC. Кипение светлячков без фильтра не оставляем.

## Геометрия

Visbuffer, два прохода окклюзии, мешлеты, конус и LOD уже потолок текущего Vulkan. Непрерывный LOD внутри мешлета — только когда ассет сам несёт уровни. Кулинг не выключать.

## Тени

Сейчас три каскада солнца в своих картах, точечные лампы в своих гранях, тексельный шаг каскада уже есть. Смещение выборки идёт вдоль нормали: `P + N * texel * sqrt(1 - NdotL^2)`.

Дальше, от дешёвого к тяжёлому:

- [x] PCSS: поиск блокировщика, ширина полутени растёт с зазором, 12 выборок диска Фогеля
- [x] SSCS — свой R8, синий шум 64×64, 0–5 см контакт, 5–20 см отдача каскаду. Режим отладки «контакт»
- [x] Эмиссив в теневую карту не кладётся. Его свет собирает Split RC
- [x] Стоячая клетка камеры не метит страницы 128. Сдвиг метит прямоугольник бокса. Каскад с тем же штампом не рисуется
- [ ] Сдвинутый каскад всё ещё рисуется целиком: проекция не мировая, старую страницу нельзя оставить
- [x] Точка — один октаэдр в карту 512×1536, не шесть граней. Прожектор — одна матрица, страница 64 или 512 по размеру на экране (`spotPage`)
- [x] Площадной свет по флагу `meta.y & 1`: форма `NdotL² * 0.5` и среднее четырёх углов. Без флага лампы прежние

Озон `(0.650, 1.881, 0.085)e-6`, пик 25 км. Радиус земли 6360 км, атмосфера 6460 км. Сила солнца гаснет `saturate((sun.y + 0.02) / 0.07)`. Стена берёт ту же панораму по полусфере, не только нормаль вверх.

## PBR — что ещё не в формуле

Уже есть сохранение энергии диффуза и спекуляра и Toksvig. Не хватает, и всё это один файл `core/brdf.slang`:

- Лак забирает свет раньше базы: база умножается на `(1 - Fcoat)`. Без этого лак светится вместе с диффузом.
- Multi-scatter GGX: LUT `E(mu, alpha)`, лепесток `f_single + f_multi`. Иначе шероховатый металл темнеет на краях.
- Диффуз Hammon вместо плоского Lambert: ретрорефлексия шершавого диэлектрика.
- Слои по флагу материала, не второй шейдер: анизотропия (`ax`, `ay`), clearcoat, sheen Charlie, иридесценция как сдвиг `F0`. Стены и пол остаются на текущем GGX.

## SSCS

Вынести из `shade_sun` в свой compute, выход `R8`. Shade только умножает готовую тень на каскад. Регистры солнца от этого не раздуваются.

- 8–16 шагов. Первые короткие, дальше шаг растёт.
- Сдвиг первого шага — Blue Noise 64×64, не фиксированный шаг. Иначе на полу кольца.
- Без накопления по кадрам. Зерно снимает один bilateral 3×3 или 5×5 по глубине и нормали.
- Толщина — зазор view-depth. Луч глубже толщины прошёл сквозь стенку.
- Край экрана гасится.
- 0–5 см — эта тень, 5–20 см — переход в CSM.

## GTAO

Половина кадра и пирамида линейной глубины. 2–3 среза, 3 шага. Вращение — Байер или Blue Noise из `core/math.slang`, не второй генератор. Апскейл bilateral до полного кадра. Bent normal, когда появится, крутит выборку той же кубмапы и SH, не новый BRDF. На ультра проход не записывается.

CMAA остаётся на старте. Он слеп к проводам и решёткам: если при ходьбе тонкая геометрия шумит, меняем на SMAA T2x, два кадра и векторы движения. Не раньше.

## Резкость и цвет

- Анизотропия 16 уже стоит. `mipLodBias = -0.3` — вместе со SMAA, не раньше: без него текстура зашумит.
- CAS, сила 0.2–0.3, один compute перед AgX. Ореол не рисовать.
- AgX уже в тонмапе.
