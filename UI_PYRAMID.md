# Пирамида `core/ui`

Просмотрены все 114 файлов `core/ui` (заголовки и исходники, около 18 тысяч строк). Код не менялся. Ниже только нарушения философии: один файл делает одну работу, соседи не лезут друг другу в поля, нижний кирпич ничего не знает о верхнем, верхний только собирает и настраивает нижние.

Целевая стопка:

1. **Рисунок.** Прямоугольник, обводка, тень, иконка, глиф, фото, клип. Никакого слайдера, галочки, кривой, меню.
2. **Узел.** Рождение, родитель, бокс, показ, имя, фокус, попадание, ввод как фазы без имён виджетов.
3. **Запись.** Виджет кладёт на себя POD и больше ничего не рисует.
4. **Кирпич.** Кнопка, поле, число, ползунок, галочка, прокрутка, строка списка. Знает только свои компоненты и кирпичи ниже.
5. **Сборка.** Меню из строк, выбор из кнопки и меню, поиск из поля, дерево и сетка из прокрутки и пула, календарь из кнопок, цвет из ползунков и поля.
6. **Страница.** Инспектор, док, хром окна, файловый путь. Собирает сборки. Живёт выше `core/ui/widget`.

Сейчас стопка лежит плашмя: общий проход рисунка знает форму галочки и ползунка, поле ввода вшито в насос ввода, на весь интерфейс [x] ~~один календарь и один цвет~~, а страница свойств сидит среди виджетов и правит их внутренности.
